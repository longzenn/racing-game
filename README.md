# 🏎️ CYBER RACER 3D - Game Đua Xe Bắt Xu 3D Đỉnh Cao

Phiên bản game đua xe 3D thế hệ mới phát triển nâng cấp toàn diện từ ý tưởng game bắt xu cổ điển, tối ưu chạy mượt mà trên **Trình duyệt Web** và **Ứng dụng độc lập trên Windows 11**.

---

## 🌟 Những Điểm Đột Phá So Với Bản Gốc
1. **Đồ Họa PBR & Hiệu Ứng Lung Linh**:
   - Ánh sáng động (Dynamic Lighting): Đèn pha chiếu rọi mặt đường, đèn phanh LED đỏ rực khi giảm tốc.
   - Hậu kỳ **Unreal Bloom**: Phát sáng rực rỡ các bảng hiệu Neon, đồng xu vàng kim và vệt lửa ống xả.
   - Hiệu ứng tốc độ **Speed Warp (Dynamic FOV)** khi bứt tốc Nitro.
   - Hệ thống hạt: Khói lốp drift, tia lửa va chạm, nổ xu vàng, bong bóng khiên năng lượng.
2. **4 Bản Đồ Đua (Map Selection)**:
   - 🏙️ **Cyberpunk Neo-Tokyo**: Đêm mưa neon phản chiếu các tòa cao ốc chọc trời.
   - 🌴 **Synthwave Sunset 80s**: Mặt trời retro khổng lồ, lưới vector tím hồng và hàng dừa nhiệt đới.
   - 🌈 **Cầu Vồng Thần Tiên HD**: Kế thừa và nâng cấp rực rỡ đường 7 sắc từ bản gốc, cây kẹo mút phát sáng và lâu đài thần tiên.
   - 🏜️ **Desert Canyon Storm**: Hẻm núi sa thạch đỏ rực hoàng hôn với lốc xoáy cát vàng.
3. **Chọn Cấp Độ Tốc Độ & Độ Khó**:
   - 🟢 **Dạo Phố (Easy - 60 km/h)**: Thư giãn, né chướng ngại vật thong thả, thích hợp cho trẻ em.
   - 🔵 **Thể Thao (Normal - 120 km/h)**: Tốc độ chuẩn, kịch tính, chướng ngại vật dồn dập.
   - 🔴 **Tử Thần (Hardcore - 200+ km/h)**: Tốc độ xé gió, thử thách phản xạ đỉnh cao.
4. **Garage Xe Đua & Tùy Biến Màu Sơn**:
   - 🏎️ **Cyber Roadster X**: Siêu xe tương lai khí động học hoàn hảo.
   - 🚀 **Phantom GT Apex**: Cỗ máy tốc độ với cánh gió kép uy lực.
   - 🚘 **Retro Interceptor**: Chiến mã cơ bắp bọc thép, ống xả kép phong cách Mad Max.
   - 🍄 **Neon Kart Vui Nhộn**: Chiếc xe mắt to tròn đáng yêu kế thừa từ bản demo gốc với đôi mắt đảo theo hướng lái!
   - 🎨 **Bảng màu sơn xe PBR**: Neon Cyan, Ruby Crimson, Solar Gold, Electric Violet, Toxic Lime, Stealth Carbon.
5. **Vật Phẩm Tăng Lực (Power-ups) & Gameplay Chuyên Nghiệp**:
   - ⚡ **Bình Nitro Boost**: Phóng vọt tốc độ tức thì, xả lửa xanh rực cháy.
   - 🧲 **Nam Châm Hút Xu**: Tự động hút toàn bộ đồng xu trong phạm vi 25m về xe.
   - 🛡️ **Khiên Năng Lượng**: Khối cầu bảo vệ hấp thụ toàn bộ lực va chạm chướng ngại vật.
   - ⭐ **Nhân Đôi Điểm (2X Multiplier)**: Nhân đôi toàn bộ điểm xu nhặt được.
   - 🚗 **Xe Giao Thông AI**: Di chuyển trên các làn đường, trao thưởng điểm thưởng "Suýt Chạm" (+50 điểm).
6. **Âm Thanh Procedural Web Audio Đỉnh Cao**:
   - Tiếng máy gầm rú theo vòng tua RPM và tốc độ km/h.
   - Tiếng xé gió Nitro, tiếng rít lốp khi chuyển làn cua gắt.
   - Hợp âm nhặt xu leng keng bắt tai, nhạc nền Synthwave/Arcade tràn đầy năng lượng (100% không cần tải file âm thanh ngoài, chạy offline ngay lập tức).

## 🚀 Hướng Dẫn Khởi Chạy Game

### Cách 1: Mở Trực Tiếp Trên Trình Duyệt Web (Nhanh Nhất)
- Nhấp đúp chuột vào file `run_game.bat` hoặc nhấp đúp trực tiếp vào file `index.html`.
- Game sẽ mở ngay trên trình duyệt mặc định của bạn (Edge, Chrome, Firefox, Brave,...).

### Cách 2: Chạy Dưới Dạng App Windows 11 Độc Lập Không Viền
- Nhấp đúp chuột vào file `launch_desktop_app.bat`.
- Game sẽ khởi chạy dưới dạng cửa sổ ứng dụng Windows 11 độc lập (không có thanh địa chỉ URL hay tab trình duyệt, giao diện như game PC cài đặt native).

### Cách 3: Cài Đặt Làm App Desktop PWA Chính Thức
- Khi đang mở game trên trình duyệt Google Chrome hoặc Microsoft Edge:
  - Bấm vào nút **"🪟 Cài đặt App trên Windows 11"** trên Menu game hoặc biểu tượng Install trên thanh địa chỉ.
  - Game sẽ được gắn vào Start Menu, Desktop và Taskbar Windows 11.

## 🎮 Hướng Dẫn Điều Khiển
- **Lái xe**: Phím `A` / `D` hoặc Phím mũi tên `◀` / `▶`.
- **Tăng tốc Nitro**: Phím `Space` hoặc `W` hoặc `Shift`.
- **Giảm tốc / Phanh**: Phím `S` hoặc Phím mũi tên `▼`.
- **Đổi góc nhìn Camera**: Phím `C` (Góc nhìn thứ 3, Góc nhìn nắp ca-pô/Cockpit, Góc nhìn Flycam).
- **Tạm dừng**: Phím `P` hoặc `ESC`.
- **Hỗ trợ Cảm ứng / Tablet Windows 11**: Có sẵn các nút bấm ảo trên màn hình.
- **Hỗ trợ Tay cầm & Vô lăng**: Cắm tay cầm Xbox / PS4 / PS5 / Vô lăng Logitech qua USB hoặc Bluetooth, game sẽ tự nhận diện cần gạt và bàn đạp ga/phanh!
